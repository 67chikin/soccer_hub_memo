 # プレミアリーグの選手情報サイト

# html

## 実践例：サッカー選手データベース（[[soccer_hub_memo]]）

### 1. 文書構造・メタデータ
- `<!DOCTYPE html>`：最新のHTML5仕様で書かれた文書であることをブラウザに伝える宣言。
- `<html lang="ja">`：ページ全体の言語が日本語であることを指定（検索エンジンや音声読み上げ、自動翻訳の誤作動防止に重要）。
- `<meta charset="UTF-8">`：文字化けを防ぐための文字コード指定。
- `<meta name="viewport" content="width=device-width, initial-scale=1.0">`：スマホやタブレットなど画面幅が異なる端末でも、表示倍率を1.0（等倍）にして正しくレスポンシブ表示させる必須タグ。

### 2. レイアウト・コンテナ設計
- `<div class="panel">`：検索フォーム全体をまとめる白い背景枠（カード型UIの親コンテナ）。
- `<div class="search-grid">`：3つの検索入力欄を横並び（[[CSS]]のGridレイアウト）にするためのラッパー要素。
- `<div id="status" class="status"></div>`：ファイル読み込みエラーなどの警告メッセージをJavaScriptから動的に流し込むための空コンテナ。
- `<div id="results" class="results"></div>`：検索結果の選手カードをJavaScriptで生成して挿入する出力先エリア。`id` はJSからの取得用、`class` はCSSでのデザイン適用と役割を分けている。

### 3. フォーム部品（ユーザー入力）
- `<input type="text" id="nameInput" placeholder="選手名 (例: さか, サカ, Saka...)">`
  - `type="text"`：1行のテキスト入力欄。
  - `placeholder`：未入力時に薄く表示される入力例・ガイドテキスト。
- `<select id="teamSelect">` / `<option value="">すべてのチーム</option>`
  - ドロップダウン（プルダウン）メニューを作る組み合わせ。初期状態では「すべてのチーム（値は空文字 `""`）」のみ用意し、残りのチーム選択肢はJSで後から `<option>` を追加している。

### 4. JavaScriptで動的に生成されるHTML要素
検索結果の描画時に、文字列テンプレートとして組み立てられるタグ群。

- `<div class="card">`：1選手分の情報をまとめるカード本体。
- `<div class="card-header">`：カード上部に「チーム名」と「背番号・ポジション」を横並び配置するためのヘッダー枠。
- `<span class="team-badge">` / `<span class="pos-badge">`
  - `<span>` は改行を伴わないインライン要素。短いテキストをラベル（バッジ）風に装飾して横に並べる際によく使う。
- `<ul class="player-details">` / `<li><span>国籍/代表：</span>...</li>`
  - 複数の詳細項目（国籍・生年月日・体格）を整理するための箇条書きリスト（Unordered List）。項目名の部分だけを `<span>` で囲むことで、CSSで太字・色変更を適用しやすくしている。
- `<pre class="raw-text">`
  - 整形済みテキスト（Preformatted Text）。改行や連続する半角スペースをブラウザに無視させず、元のテキストデータのレイアウトのまま画面に出力する。

 # サッカー選手データベース CSS構成メモ

## 1. 全体レイアウト・タイトル
| セレクタ | 対象（HTMLのどこ） | 役割・やっていること |
| :--- | :--- | :--- |
| `body` | ページ全体 | フォント種類、薄いグレーの背景色、文字色、最大幅（1000px）と中央寄せ（`margin: 0 auto`）を設定 |
| `h1` | ページ上部の大見出し | テキストの中央揃え、下側の余白（24px）を設定 |

## 2. 検索フォームエリア
| セレクタ | 対象（HTMLのどこ） | 役割・やっていること |
| :--- | :--- | :--- |
| `.panel` | 検索欄を囲む白い箱 | 白背景、内側の余白、角丸（10px）、薄い影（`box-shadow`）でカード風の枠を作成 |
| `.search-grid` | 入力欄3つを並べる枠 | 画面幅に応じて入力欄を横並び・自動折り返しにするグリッドレイアウト |
| `input[type="text"], select` | テキスト入力欄とプルダウン | 幅100%（枠線込みのサイズ計算 `border-box`）、内側の余白、薄いグレーの枠線を設定 |
| `.status` | エラー・警告メッセージ欄 | 上の余白、オレンジ色の太字を設定 |
| `.status:empty` | メッセージが空のとき | 文字が入っていない場合は非表示（`display: none`）にして余計な隙間をなくす |

## 3. 検索結果エリア（一覧・案内）
| セレクタ | 対象（HTMLのどこ） | 役割・やっていること |
| :--- | :--- | :--- |
| `.results` | 選手カードを並べる一覧エリア | 最小幅290pxのカードを画面幅に合わせて自動で敷き詰めるグリッドレイアウト |
| `.guide-message` | 初期表示の案内文 | 文字色を落ち着いたグレーに設定 |

## 4. 選手カード（1人分の表示枠）
| セレクタ | 対象（HTMLのどこ） | 役割・やっていること |
| :--- | :--- | :--- |
| `.card` | 選手1人分の白いカード | 白背景、角丸、薄い影に加え、上辺だけに青い太線（`border-top: 4px solid #2563eb`）を引く |
| `.card-header` | カード上部（バッジ2つの行） | `display: flex` と `space-between` でチーム名と背番号・ポジションを左右の端に配置 |
| `.team-badge` | チーム名のラベル | グレー背景・角丸の小さなバッジ風デザイン |
| `.pos-badge` | 背番号・ポジションのラベル | 薄い青背景・青文字・角丸の小さなバッジ風デザイン |
| `.player-name` | 選手名 | 大きめの太字（18px）、濃い紺色で目立たせる |
| `.player-details` | 国籍・生年月日・体格のリスト | リストの黒丸（`・`）を消し、行間を広め（1.7）にして読みやすく調整 |
| `.player-details span` | 「国籍/代表：」などの項目名 | 項目名だけを太字・濃い色にして値と区別しやすくする |
| `.raw-text` | 整形されていないテキストデータ | 元のテキストの改行やスペースをそのまま表示（`white-space: pre-wrap`） |

## 重要プロパティまとめ
- **`display: grid` / `display: flex`**：要素を横並びや格子状に整列させるための仕組み。
- **`box-sizing: border-box`**：`width: 100%` にしたとき、枠線や内側余白（`padding`）のせいで親枠からはみ出すのを防ぐ指定。
- **`:empty`**：中身が空の要素にだけスタイルを適用する擬似クラス。

# 表示サイズ変更機能（追加分）メモ

## 1. CSS（`style.css` に追加した部分）
| セレクタ・記述 | 対象（HTMLのどこ） | 役割・やっていること |
| :--- | :--- | :--- |
| `:root { --card-scale: 1; }` | ページ全体（ルート要素） | 倍率を管理するCSS変数 `--card-scale` を定義（初期値は `1`＝100%） |
| `.size-control` | スライダー周辺の操作エリア | `display: flex` でラベル・スライダー・数値・ボタンを横並びに配置し、上に区切り線を引く |
| `.size-control input[type="range"]` | サイズ調整スライダー | 幅を180pxに固定し、マウスカーソルを指マーク（`pointer`）にする |
| `#sizeValue` | 「100%」などの数値表示 | 桁数が変わっても横のボタンがガタつかないよう最小幅（`min-width: 45px`）を確保 |
| `.reset-btn` | リセットボタン | グレー背景・角丸の小さなボタンデザイン |
| `.reset-btn:hover` | リセットボタン（ホバー時） | マウスを乗せたときに背景色を少し濃くする |
| `.results`（変更） | 選手カード一覧のグリッド | `min(100%, calc(350px * var(--card-scale)))` により、倍率に合わせて1列の幅を広げつつ、画面幅ははみ出さないように制御 |
| `.card`（追加） | 選手カード1枚 | `zoom: var(--card-scale);` でカードの箱・余白・文字サイズをすべて倍率通りに拡大・縮小 |

## 2. HTML・JavaScript（`soccer.html` に追加した部分）
| 要素・関数 | 役割・やっていること |
| :--- | :--- |
| `<input type="range" min="0.7" max="2.5" step="0.05">` | 70%（`0.7`）〜250%（`2.5`）まで5%刻みで動かせるスライダー |
| `updateCardScale(scale)` | CSS変数 `--card-scale` の値を書き換え、画面上の「〇〇%」表示を更新する関数 |
| `sizeSlider.addEventListener('input', ...)` | スライダーを動かしている最中にリアルタイムで `updateCardScale` を実行する |
| `resetSizeBtn.addEventListener('click', ...)` | リセットボタンを押したときにスライダーと倍率を `1`（100%）に戻す |

## 重要テクニックまとめ
- **CSS変数（`--変数名`）**：CSS側で `var(--card-scale)` と書いておき、JavaScriptの `style.setProperty()` で値を書き換えることでデザインを動的に変更できる。
- **`zoom` プロパティ**：要素全体の表示倍率を変える指定。`font-size` や `padding` を個別に計算し直さなくても、箱と文字の比率を保ったまま拡大・縮小できる。
- **`min(100%, ...)`**：拡大して計算上の幅が親要素（画面幅）を超えた場合でも、最大100%で止めて横スクロールやはみ出しを防ぐ関数。
